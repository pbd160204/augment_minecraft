# Augment Survival PvP Datapack

Minecraft Java Edition `26.3`용 렐름/멀티플레이 야생 PvP 데이터팩입니다. 경기장 안에서 자원을 모으고, 증강을 누적해 최후의 생존자가 되는 방식입니다.

## 설치와 적용

1. 월드의 `datapacks` 폴더에 `augment_datapack` 폴더를 넣습니다.
2. 월드에 접속한 뒤 `/reload`를 실행합니다.
3. `/datapack list`에서 `file/augment_datapack`이 활성화되었는지 확인합니다.
4. 문제가 있으면 `logs/latest.log`에서 `augment` 함수 오류를 확인합니다.

## 운영자 명령

운영자 권한(Level 2 이상)이 있어야 다음 함수를 실행할 수 있습니다.

| 명령 | 기능 |
| --- | --- |
| `/function augment:admin/set_arena` | 현재 위치를 중심으로 1000×1000 경기장을 설정합니다. |
| `/function augment:admin/reset_arena` | 경기가 진행 중이 아닐 때 경기장을 다시 설정합니다. |
| `/function augment:admin/start` | 경기 시작 및 참가자 초기화. |
| `/function augment:admin/pause` | 게임 틱과 플레이어 행동을 일시 정지합니다. |
| `/function augment:admin/resume` | 일시 정지를 해제합니다. |
| `/function augment:admin/stop` | 경기를 중단하고 로비 상태로 정리합니다. |
| `/function augment:admin/show_help_all` | 모든 플레이어에게 도움말을 표시합니다. |
| `/function augment:admin/give_shop_remote_all` | 모든 플레이어에게 상점 리모컨을 지급합니다. |

## 경기 흐름

1. **시작**: 각 참가자는 경기장 안의 서로 떨어진 랜덤 지점으로 이동하며, 해당 지점이 스폰 지점이 됩니다. 인벤토리는 비워지고 체력·허기 수치가 최대치로 초기화됩니다.
2. **자원 수집 (45분)**: 플레이어 PvP는 차단되고 `keepInventory`가 적용됩니다. 사망 후 리스폰하면 5초간 무적입니다.
3. **자동 경험치**: 3분마다 경험치를 지급하며, 지급량은 매 회차마다 15%씩 증가합니다. 레벨이 4의 배수가 될 때마다 일반 증강 선택권을 얻습니다.
4. **사전 알림**: PvP 시작 10분·5분·3분·1분 전에 전체 알림이 표시됩니다.
5. **PvP**: 플레이어 간 전투가 허용되고, 일반 사망자는 탈락하여 관전 모드가 됩니다. 월드보더는 5분마다 새 중심을 정한 뒤 다음 5분 동안 축소됩니다.
6. **보급**: PvP 중 5분마다 현재 보더 경계에서 100칸 이상 떨어진 위치에 보급 워든과 신호기가 출현합니다. 보급 워든을 처치하면 경험치 800, 기본 보상 및 보급 전용 아이템을 얻습니다.
7. **데스 매치**: 최종 보더에 도달하면 자동 경험치가 중단됩니다. 10분 후 보더가 4×4까지 줄어듭니다.
8. **종료**: 생존자가 한 명이 되면 우승자를 표시하고 정리합니다. 종료 후 일반 플레이어는 로비 좌표에서 모험 모드로 고정됩니다.

## 플레이어 조작

| 방법 | 기능 |
| --- | --- |
| `/trigger ag_help set 1` | 도움말 표시 |
| `/trigger ag_menu set 1` | 보관 중인 일반 증강 선택권으로 메뉴 열기 |
| `/trigger ag_advmenu set 1` | 보관 중인 고급 증강 선택권으로 메뉴 열기 |
| 증강 도감 리모컨 | 현재 보유한 증강과 간략 설명 확인 |
| 증강 선택 리모컨 | 일반 증강 선택 메뉴 열기 |
| 상점 리모컨 또는 대장장이 작업대 우클릭 | 상점 열기 |

증강 선택은 클릭형 `tellraw` 메뉴입니다. 선택하지 않은 선택권은 보관되며, 이미 보유한 증강은 다시 제시되지 않습니다.

## 증강 계열과 시너지

증강은 중첩되며, 계열별 보유 개수에 따라 시너지가 활성화됩니다. 계열별 중첩 현황은 액션바에 표시됩니다.

| 계열 | 메뉴 색 | 시너지 임계값 |
| --- | --- | --- |
| 생존 | 노랑 | 3 / 4 / 5 / 7 |
| 성장 | 초록 | 4 / 5 |
| 전투 | 빨강 | 5 / 6 / 7 |
| 마법사 | 보라 | 4 / 6 / 10 |
| 채굴 | 하늘색 | 3 / 4 / 5 |
| 퀘스트 | 흰색 | 없음 |

- 퀘스트 계열 일반 증강은 **24레벨 이하**에서만 등장합니다.
- 고급 증강은 일반 선택지에 등장하지 않으며, 고급 선택권 또는 연금술 효과로만 획득합니다.
- `<옴의 법칙>`은 **고급 생존 증강**입니다.
- `<불공정계약>`은 고급 증강이며, 다른 퀘스트 2개를 완료하면 보유 증강의 패널티 효과를 해제합니다.

## 상점과 채굴 시너지

상점은 다이아몬드를 기본 화폐로 사용합니다. `<김승언>`의 농사 촉매를 사용한 뒤에는 특수 상점으로 전환되어 비료를 화폐로 사용합니다.

- 채굴 **3중첩**: 기본 상점 품목 가격이 30% 할인됩니다. 표기 가격도 할인값으로 표시됩니다.
- 채굴 **4중첩**: 폭죽, 황금사과, 겉날개, 철퇴 등 고급 품목이 해금됩니다.
- 채굴 **5중첩**: 겉날개 가격이 추가로 50% 할인됩니다.
- `<쓰까크래프트>` 보유자: 광물 원석 드롭이 경기마다 새로 생성되는 비공개 교환표로 바뀌며, 다이아몬드 상점 가격은 3배가 됩니다. 채굴 할인은 3배 가격에 적용됩니다.
- `<황금 고블린>` 보유자: 금 주괴로 구매하는 특수 금 장비 상점이 해금됩니다.

## 보급

보급 워든은 공격하거나 이동하지 않는 체력 500의 목표입니다. 신호기 기둥과 워든 체력 디스플레이로 위치와 진행도를 확인할 수 있습니다. 보급은 처리하지 않아도 자동 소멸하지 않습니다.

현재 보급 전용 아이템은 다음과 같습니다.

- `[꺼져!]`: 내구도 3의 밀치기 XV 나무 삽
- `[인챈트 리롤러]`: 왼손 아이템의 인챈트를 제거하고 30레벨 인챈트를 다시 부여
- `[텟카이]`: 10초간 구속 255·저항 255 및 모루 파티클
- `[진짜 투명화]`: 투구를 제외한 착용 갑옷을 숨기고 1분간 투명화
- `[발광 차폐막]`: 왼손에 들면 증강으로 인한 발광 갱신을 차단
- `[파상풍 화살]`: 5발 지급. 적중 시 실명·어둠·메스꺼움·발광·나약함·허기·독·공중 부양 I, 구속 II를 적용하는 회수 불가 화살

## 기본 제한

- 경기 중 네더와 엔드 진입은 차단됩니다.
- 방패, 황금사과, 쇠뇌, 침대, 리스폰 정박기, 인챈트 테이블, 모루, 숫돌은 제작할 수 없습니다. 활은 제작할 수 있지만 인챈트할 수 없으며, 제작 결과에 소실 저주가 부여됩니다.
- 주민은 경기 진행 중 매 틱 제거됩니다.
- 침대와 리스폰 정박기로 스폰 지점을 변경할 수 없습니다.

## 테스트 점검 항목

`/reload` 후 다음을 확인합니다.

1. 일반 증강 메뉴에는 `<옴의 법칙>`이 나오지 않고, 고급 메뉴에는 등장하는지 확인합니다.
2. 채굴 3·4·5중첩에서 상점 표기 가격과 실제 결제 가격이 일치하는지 확인합니다.
3. PvP 시작 후 보급 보스바, 보급 출현 알림, 신호기·워든 생성을 확인합니다.
4. 경기 종료 후 월드보더 해제와 로비 정리 상태를 확인합니다.
